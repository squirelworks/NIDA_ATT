# _inferred

Where the 717 official lessons sit. This is the master before it was cut down to the books in `courses/`.

| Path | What it is |
|---|---|
| `nida.curriculum.json` | All 717 lessons: group, module, and title. |
| `master.xml` | The same list as a Foolcourse menu. Seven ATT subjects. |
| `titles.json` | The title for every one of those ids. |
| `absent.json` | The 106 lessons on that map with no `.fbk` in `courses/`. |

The live master is `_curriculum/nida.curriculum.json` and `_curriculum/master.xml`. It keeps a lesson only when the book is in the repo, and it keeps the module number, so a gap stays a gap.

Ratings and programs under `_curriculum/` are the disk menus. They still name lessons that are not in `courses/`.
